# Follow-up Call Scripts  (≤ 5 minutes; Urdu draft + English gloss)

> Ask the farmer to **explain a message in their own words** — that measures
> understanding far better than "haan/nahin". Native-check the Urdu first.

## Day 3
1. کیا پیغام آپ تک پہنچے؟  (Did the messages reach you?)
2. آپ نے پڑھا یا سنا؟  (Did you read or listen?)
3. ایک پیغام اپنے الفاظ میں بتائیں — اس کا کیا مطلب تھا؟  (Explain one message in your own words.)
4. کیا آپ نے اس پر عمل کیا؟  (Did you act on it?)
5. کیا کچھ سمجھ نہیں آیا؟  (Anything confusing?)

## Day 7
1–5 as above, plus:
6. تحریر (SMS) یا آواز — آپ کو کیا بہتر لگا؟  (Text or voice — which did you prefer?)
7. آپ آگے کیا جاننا چاہیں گے؟  (What would you want next?)
8. کیا آپ اسے استعمال کرتے رہیں گے؟  (Would you keep using it?)

Record each answer in `feedback_log.csv`. For Q3, score: understood / partly / not.
