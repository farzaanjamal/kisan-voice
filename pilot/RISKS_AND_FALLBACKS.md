# What can go wrong → fallback

| Risk | Early sign | Fallback |
|---|---|---|
| No agronomist replies in time | silence by day 4 | run **Version B** (no approved advice needed); keep asking more experts |
| Few farmers recruited | <10 by day 2 | shrink to a comprehension study; reach via 2nd dealer/village contact |
| SMS not delivered | gateway errors / no reply | check SIM balance + rate limits; resend once; log failures honestly |
| Farmers not reading SMS | low day-3 recall | offer voice notes (V1) via WhatsApp to those who prefer voice |
| Phone can't show Urdu script | garbled text reported | send **Roman Urdu**; record which phones failed (useful finding) |
| Native-speaker check slow | no reply by day 3 | delay sending; never send unverified non-Urdu text to a farmer |
| Low literacy blocks text | farmer can't read | voice-first for that farmer; record as evidence for the voice channel |

The honest move everywhere: if a channel isn't ready, don't fake it — record the
gap as a finding. "7 of 22 phones couldn't render Urdu script" is a real result.
