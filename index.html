Kisan Voice

Farming advisories for small farmers in low-connectivity Pakistan: the advice lives in an offline dictionary, so only a tiny code (~9 bytes / one SMS) has to travel — and any phone that holds the dictionary speaks the full message in Urdu.

Pick an advisory. The page encodes it to an SMS code and a Bluetooth packet, then decodes it back — using the exact same rules as the Python package, verified identical on all 367 entries.

Regional languages (Sindhi, Pashto, Saraiki) are planned — they need a native speaker, so the draft ships Urdu + Roman Urdu only.

3Evidence

Real numbers from the code in this repo. Pilot numbers are not invented — they appear only after a real pilot.

Compression — why not just gzip?

Because the win isn't clever compression; it's that the receiver already holds the dictionary, so only a reference travels. Across all three draft dictionaries (367 advisories), the median message is about 93.0% smaller as a binary code, and 135 messages that would need two SMS collapse into a single code.
